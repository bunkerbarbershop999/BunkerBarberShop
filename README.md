# Barbería Enzo

Sistema de gestión + turnero. Mismo formato que Royal Essence: HTML sueltos + Supabase, sin compilar.

- `gestion/`  panel privado de Enzo
- `turnero/`  formulario público para pedir turno (se manda el link por WhatsApp)
- `config.js` URL y clave de Supabase + WhatsApp
- `supabase.sql` tablas, triggers de caja y seguridad (correr UNA vez en Supabase)
